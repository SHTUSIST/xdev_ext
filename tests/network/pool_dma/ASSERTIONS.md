# Frozen independent assertions and adapter boundary

Frozen before reading the production bodies. Source: supplied ordinary DATA CONTRACT §§3–8. Fixture: three original frame indices 0,1,2, 4096-byte chunks, data_off=64, data_len=16; packet starts at offset 22, length 58, ending at payload end 80. UMEM bases are literal 0,4096,8192; admitted descriptor addresses 22,4118,8214; raw map device is NIC-A, mapped pages 0x100000,0x300000,0x500000. Payload bytes are distinct per original frame. CPU pointers intentionally bear no relationship to DMA values.

1. Full/partial/no-unsent submit preserves original descriptor bytes/options, IPv4 checksum and zero UDP checksum, sent tag, CQE/frame status, NIC counters and trace order. Per unsent descriptor: finish → raw lookup → device sync → descriptor_bind → sent tag. Device sync is to NIC-A, BIDIRECTIONAL, entire 58-byte header-prefix packet, addresses 0x100016/0x300016/0x500016; partial sent index 1 must retain original frame index 2 for the second new descriptor.
2. Old preflight priority: stopped/dead/unbound returns ENXIO ahead of fatal/capacity; reserve fatal ahead of capacity; fatal/capacity ahead of any new mapping check. No native effects on preaccept failure. No-unsent performs original completion without native publication.
3. Wakeup error at 0/1/3 native peeks returns accepted 0; only never-native suffix is canceled. Native uncertainty remains until definite completion. Core/stage callbacks happen outside tx_lock; wakeup has socket mutex held and provider lock dropped.
4. Native tail cancellation may leave a DONE hole before the head. Native FIFO is independent of reclaimed cursor. set_only changes first error without retirement or lease release. Accepted native EAGAIN is terminal EIO in normalized journal/fatal channel; original raw native_error handoff remains distinct. Excess count stops/sequesters. Mixed stop PENDING/NATIVE/DONE retains unknown native lease, clears only definite leases; after unmap late completion performs no DMA map access.
5. Family API literal guard priority: null lease/batch/ops/check/owner→EINVAL; zero length→EPROTO; invalid frame_pos→ERANGE; absent pool/bad index/data geometry→EINVAL; prefix/end mismatch→ERANGE; occupied lease→EBUSY; provider callback exact result. Every failure preserves every byte of preexisting lease; no callback before provider stage. Successful metadata: owner provider, base 0/4096/8192, original index, frame_off=22, len=58, kind=3. Unknown release preserves full lease; true release zeros only pool union member and kind. Other kinds untouched.
6. Provider guard priority: wrong ops/priv/non-ZC→EINVAL; stopped/missing xp/umem/dev/pages or page count mismatch→ENXIO; current pool/UMEM/pages/chunk/frame/heads association mismatch→EXDEV; unaligned/wrong base/wrong frame handle/UMEM or mapped-array span overflow→ERANGE. kaddr must not authorize DMA. Valid mapping check and sync/publication occur in one uninterrupted tx_lock critical section. Replaced mapping after stop never readmitted.
7. All unsent leases must be acquired after reserve before any checksum/sync/descriptor/trace/tag. Failure at original index 2 restores prod, clears exactly newly acquired index 0 prefix, retains unrelated occupied index 1, and produces no new externally visible effects or completion. Zeroing an occupied lease to acquire succeeds incorrectly and must fail the test.
8. Candidate adapter may expose only production types, fields and symbols. No candidate algorithm or state machine is permitted in adapter. API absence or inability to compile is SETUP. Semantic RED requires executable production code returning/asserting the wrong result. Mutants count only when compilation succeeds, process exits via designated assertion and its named assertion is present; crashes and compiler errors are not semantic evidence.

Boundary doubles: locking/RCU only record held state; DMA raw accessor uses actual production body over controlled mapped-page array, DMA sync records OS call arguments; wakeup may call actual public peek hook; completion/counters record outward calls; kernel list mechanics are conventional intrusive list operations. No substitute family/provider/journal behavior. Reliable and policy fallback boundaries remain controlled branches because they are out of this slice; their full regression remains root-owned.
